To use the program, first double-click the setup_and_run_portable file. This is an automatic script，the script will automatically install the required dependencies and then open the web app in your browser. 
After the page loads, enter the ZIP code of the area you want to view (for example: 11370, 11691, or 11412) and click Search to generate the map of listings. You can zoom in and out freely on the map, and click any marker to see detailed information about that property. 
In the Buy-Timing Advisor section, you can enter your annual income and an estimated comparable monthly rent; the tool will then help you evaluate whether buying this property is suitable for you.
